💻Binary to Decimal Converter

A Python program that converts a binary number into its decimal equivalent without using the built-in `int(binary, 2)` function.... 🐍

🖇️Algorithm

1. Take a binary number as input.
2. Traverse the digits from right to left.
3. Multiply each digit by 2 raised to its position.
4. Add the results.
5. Display the decimal equivalent.

📍Example

• Input:
1011

Output:
11
